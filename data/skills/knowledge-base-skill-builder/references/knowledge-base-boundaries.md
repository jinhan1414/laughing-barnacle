# 知识库的边界

“知识库型 Skill”在这里指的是：
- 一个围绕特定主题整理好的 Skill
- 它把权威来源、概念分层、仓库实现、回答方式组织成可按需读取的能力包

它不等于：
- 任意一堆 markdown 文档
- 单纯的向量库
- 单纯的 Prompt 模板
- 单纯的 MCP 服务配置

和向量检索的关系：
- OpenAI Retrieval / File search 说明了“文档如何被索引和检索”。
- 这适合回答“如果资料很多、经常搜索原文，知识库应该如何做检索层”。
- 但知识库型 Skill 更偏向“组织知识与回答框架”，不等于一定要上向量库。

和 MCP 的关系：
- MCP 适合把外部知识源或工具暴露给 Agent。
- 若知识库在外部系统，需要被远端搜索/读取，MCP 是一个暴露方式。
- 但“知识库型 Skill”本身仍然负责告诉 Agent：什么时候查、先查什么、如何解释结果。

和本仓库 Skill 的关系：
- 本仓库的 Skill 先走索引注入，再按需读 `SKILL.md` 和 `references/*.md`。
- 因此最适合承载：
  - 主题型知识库
  - 协议知识库
  - 平台能力知识库
  - 仓库实现知识库

何时不该做成知识库型 Skill：
- 只是一次性问题
- 没有稳定主题边界
- 没有权威来源
- 内容主要是执行脚本，而非知识组织
