# A2A 排障

## 默认排查顺序

1. 触发条件是否进入正确的 A2A 维护或执行链路。
2. Agent Card 是否可读，且关键字段完整。
3. `skills` 是否存在且满足当前可执行约束。
4. send/get/cancel 是否真正发出并返回。
5. 任务状态、artifact、日志、事件流是否支持当前结论。

## 常见问题

### Agent Card 发现失败

- 核对 `agent_card_url` 是否可访问。
- 核对鉴权是否正确。
- 核对路径是否真的是 Agent Card，而不是普通页面。

### `skills` 校验失败

- 优先看 Card 是否缺失 `skills`。
- 若是可执行 Agent，空数组同样应视为不合法。
- 本仓库对此有显式拒绝逻辑，不应做静默降级。

### 任务状态异常

- 区分协议状态与产品编排策略。
- 先看远端 task 状态，再看本地是否因为“禁止同轮轮询扩张”而提前直返。

### 声称完成但无证据

- 必须回到 task/status/artifact/日志。
- 只有进程退出码或模型自然语言回复，不足以证明 A2A 任务完成。
